# Общий каталог

Telegram-бот с Mini App, через который участники чата делятся вещами, книгами и услугами.

- **Круг** — групповой чат, в который добавили бота. Участник чата = участник круга.
- **Круги создаются по приглашению.** Администратор (владелец сервиса) командой `/invite` получает одноразовую ссылку; её получатель может добавлять бота в свои чаты. Если бота добавил неприглашённый человек, бот объясняет это и выходит из чата. Команда `/circles` показывает администратору все круги.
- **Каталог** открывается внутри Telegram: поиск, фильтры, фото, статус «у кого сейчас».
- **Запрос** проходит путь: ждёт ответа → принят → передано → возвращено. Услуги завершаются без шага передачи.
- **Уведомления**: новинки — в чат круга, запросы и смены статуса — в личку, напоминание о сроке возврата — раз в день.
- **Не шумит**: при добавлении можно снять галочку «Сообщить в чат круга», а команда `/here`, отправленная в теме чата, направляет новинки в эту тему.
- **Два языка**: английский (основной) и русский. Человек выбирает язык переключателем EN / RU на вкладке «Моё» или командой `/lang` в личке с ботом; язык сообщений бота в чате меняет `/lang` в самом чате (администратор чата или создатель круга). По умолчанию язык берётся из настроек Telegram.
- **Правила, ответственность и данные**: при первом открытии каталога человек видит правила, отказ от ответственности администратора и уведомление об обработке данных (GDPR) и должен согласиться; без этого публиковать и просить нельзя. Согласие и его дата хранятся в базе. Тексты — в `web/src/termsText.ts`; при существенном изменении увеличьте `TERMS_VERSION` в `worker/src/types.ts`, и всех попросят согласиться заново. Те же тексты есть на лендинге и по адресу `/#/terms`.
- **Лендинг**: адрес сервиса, открытый в обычном браузере, показывает описание бота.

## Локальный запуск

```bash
npm install
npm run dev
```

При первом запуске создаётся `.dev.vars` из образца `.dev.vars.example` — только локальные значения, в git он не попадает.

Откройте `http://localhost:8787/?user=1` (а также `?user=2`, `?user=3` — разные тестовые люди; третий состоит только в одном из двух тестовых кругов). Сообщения бота в этом режиме не отправляются, а пишутся в консоль.

```bash
npm test          # автотесты
npm run typecheck # проверка типов
```

## Развёртывание

Нужны аккаунт Cloudflare (для R2 — с привязанной картой, на таком объёме бесплатно) и бот, созданный в @BotFather.

1. `npx wrangler login`
2. `npx wrangler d1 create sharing-circle` — вставьте выданный `database_id` в `wrangler.toml`
3. `npx wrangler r2 bucket create sharing-circle-photos`
4. `npm run deploy` — в конце покажет адрес вида `https://sharing-circle.<поддомен>.workers.dev`
5. `./scripts/setup.sh <этот адрес>` — спросит токен бота, сохранит секреты и подключит вебхук
6. В @BotFather включите Mini App (скрипт напомнит, где именно)
7. Откройте в Telegram секретную ссылку, которую покажет скрипт, — так вы станете администратором

После этого добавьте бота в групповой чат, а другим людям раздавайте приглашения командой `/invite`. Если кто-то из участников не может попасть в круг, сделайте бота администратором чата: Telegram гарантирует проверку членства только для ботов-администраторов.

## Устройство

| Папка | Что внутри |
|---|---|
| `worker/src` | Сервер на Cloudflare Workers: `api.ts` (HTTP API), `bot.ts` (обработка сообщений Telegram), `flow.ts` (правила смены статусов), `notify.ts` (уведомления), `i18n.ts` (тексты бота на двух языках), `auth.ts` (проверка подписи Telegram) |
| `worker/migrations` | Схема базы D1 |
| `web/src` | Mini App и лендинг на React; все тексты интерфейса — в `i18n.ts` |
| `test` | Автотесты: подпись, статусы, видимость по кругам, сценарии бота |

Таблица `events` хранит журнал всех действий — на её основе позже можно ввести баллы или банк времени.
